# 飞书接入清单（真实连接前）

本清单只在插件骨架完成后使用。现在不需要执行，也不要把任何密钥发到聊天或提交到 GitHub。

## 在飞书开放平台创建应用

1. 创建“企业自建应用”，开启机器人能力。
2. 配置事件订阅的回调地址为你自己部署的 HTTPS 地址，例如 `https://your-domain.example/feishu/events`。
3. 记录 App ID、App Secret、Verification Token 与 Encrypt Key；它们只保存在本机用户级安全配置中。
4. 仅申请第一版必要的消息/机器人权限；不要一开始申请读取全组织历史消息的宽泛权限。
5. 将机器人添加到一个明确授权的测试群，由群管理员发送测试命令。

## 第一版验收

- 飞书能够完成 URL 校验；
- 收到“帮助”命令时，机器人返回使用边界；
- 收到“分析本线程”时，只创建待确认的分析任务，不自动读取额外历史；
- 返回卡片包含：分析范围、已脱敏提示、证据要求、人工确认提醒；
- 所有真实消息和模型 Key 均不进入日志、仓库或测试样例。
